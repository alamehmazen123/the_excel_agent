v1.14.2 - Fixes the Pivot Analysis sheet on re-generated files. The source data Table was keeping its old narrow range on re-runs, so the engine's decoded-name and sign-flipped helper columns fell outside it and never reached the PivotCache - which is why pivots came out empty and showed raw codes. The table is now widened every run, so pivots have their values and group by real names (Department/Payer/Doctor). Pivots no longer group by junk columns (Cost, description, patient name). Plus: friendly value captions, a 'By account category (revenues vs expenses)' roll-up, and a Data Quality panel listing any codes not yet in the library.
